# 🛠️ IntelliAttend Technology Stack

A unified list of the technologies powering the IntelliAttend ecosystem.

## 📱 Mobile Applications (Student & Faculty)
-   **Framework:** Flutter (Dart)
-   **UI:** Material 3, Lottie (Animations), Syncfusion (Charts)
-   **Auth:** Firebase Authentication
-   **Real-time:** Cloud Firestore
-   **Scanning:** ML Kit (Vision API)
-   **Security:** Play Integrity (Android) / App Attest (iOS)

## ⚙️ Backend Engine
-   **Language:** Python 3.11+
-   **Web Framework:** FastAPI
-   **Serialization:** Pydantic v2
-   **Server:** Uvicorn / Gunicorn
-   **Architecture:** Hexagonal-inspired (Adapters & Ports)

## 🌐 Web Portals (Admin & SmartBoard)
-   **SmartBoard:** Vanilla JS, HTML5 Canvas, WebSockets (Socket.io)
-   **Admin Portal:** Modern Responsive Web (HTML/CSS/JS)

## ☁️ Infrastructure & DevOps
-   **Hosting:** Google Cloud Platform (GCP) / Firebase
-   **CI/CD:** GitHub Actions
-   **Containerization:** Docker (Backend)
